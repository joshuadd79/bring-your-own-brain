Architecture

How It Works

No servers to deploy, no API keys to hide, and no token invoices. Compute belongs to the player.

🧩

1. Dev Drops 1 Line

Add a single <script> tag to your web game or app. Mount the connect button in any div or let it float bottom-right. Zero backend required.

⚡

2. User Connects Hardware

In this initial release, the player clicks "Connect Local AI". An isolated sandbox loads the lightweight Qwen2.5 0.5B (more model options are being added regularly) open model directly onto their graphics card via WebGPU (with automatic WASM CPU fallback).

🛡️

3. Zero-Token Streaming

Inference streams straight into your game logic at native frame rates. No user prompts ever leave the browser, and you never pay an AI API token bill.

Developer Quickstart

Get the 1-Line AI-Connector SDK

Drop this into any HTML page. Works in pure JavaScript, React, Canvas, Phaser, or Matter.js.

game.html 
<!-- 1. Load the BYOB Web SDK (No extension needed) -->
<script src="https://bringyourownbrain.org/byob-web-sdk.js"></script>

<!-- 2. Mount the connect button in your UI -->
<div id="ai-connector"></div>

<script>
  const brain = new BringYourOwnBrainWeb({
    container: document.getElementById('ai-connector'),
    width: '220px',
    height: '44px',
    onState: (state) => console.log('BYOB State:', state)
  });
  
  brain.mount();

  // 3. Stream or await responses directly from the player's GPU:
  async function talkToNPC(playerText) {
    brain.onChunk = (token) => renderSpeechBubble(token);
    
    const reply = await brain.chat([
      { role: 'system', content: 'You are a sarcastic goblin bouncer. Answer in 1 short sentence.' },
      { role: 'user', content: playerText }
    ], { max_tokens: 60, temperature: 0.7 });
  }
</script>

⚡ WebGPU Hardware Acceleration

Uses WebLLM to run open weights models on Apple Silicon, Nvidia, and AMD GPUs.

🛡️ Universal WASM Fallback

If WebGPU is unavailable or disabled, the engine automatically falls back to CPU via Transformers.js with zero code changes.

Trust & Governance

Legal & Privacy Statement

Built on radical local privacy and open-source transparency.

🔒 100% Client-Side Privacy

bringYourOwnBrain.org operates zero server-side inference or telemetry pipelines. When a user interacts with an AI model:

  • Zero prompts, inputs, or outputs are ever transmitted to our servers.
  • Inference executes entirely inside the client’s browser memory (VRAM / RAM).
  • No third-party tracking cookies or advertising pixels are used.

⚖️ Open Weights & Licensing

The BYOB Web SDK and connection bridge are open-source under the Apache 2.0 License.

  • Model weights (Qwen2.5 family - noted here as it is used in the initial release) are created by Alibaba Cloud and provided under the Apache 2.0 license via Hugging Face.
  • Developers are free to embed the SDK in commercial or non-commercial games with no licensing fees owed to BYOB.
